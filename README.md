# autobiz-updates

Danh sách phiên bản AutoBiz có chữ ký Ed25519 (`feed.json`), để các bản AutoBiz tự cài kiểm tra bản mới.
Không chứa mã nguồn. Bản cài đặt `AUTOBIZ_UPDATE_FEED=https://100questions.github.io/autobiz-updates/feed.json` và `AUTOBIZ_UPDATE_PUBKEY` (khoá công khai);
feed sai chữ ký bị bỏ qua.
